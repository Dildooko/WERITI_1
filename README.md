# WERITI

Учебный сайт-магазин свежего зелёного винограда. Выбираете сорт, добавляете его в корзину, оформляете заказ.

Сайт полностью статический: у него нет собственного сервера. Все данные хранятся **только в браузере пользователя** и записываются на диск **в зашифрованном виде**.

## Возможности

- Регистрация и вход по логину и паролю.
- Каталог из шести сортов винограда с описанием и ценой за 1 кг.
- Корзина с изменением количества (от 1 до 99 кг) и подсчётом итоговой суммы.
- Фото профиля: выбранная картинка обрезается до квадрата и сжимается до 160×160 пикселей.
- Звуки: мягкий щелчок при нажатии на кнопки, звонкий аккорд при успехе и низкий сигнал при ошибке.
- Спокойная фоновая музыка после входа. Звук и музыку можно выключить кнопкой с динамиком. Настройка запоминается отдельно для каждого пользователя.
- Реакция кнопок на наведение мыши, нажатие и касание, включая волну от места касания.
- Адаптивная вёрстка для телефона и компьютера. Если в системе включено «уменьшить движение», анимации отключаются.

## Как устроено хранение данных

- Для каждого пользователя создаётся отдельная база SQLite. Она работает в браузере через библиотеку [sql.js](https://github.com/sql-js/sql.js).
- Перед записью в `localStorage` база шифруется алгоритмом **AES-256-GCM**. Ключ получается из пароля через **PBKDF2** (SHA-256, 600 000 раундов) и хранится только в памяти открытой страницы.
- Пароль нигде не сохраняется. Верный пароль проверяется самим шифрованием: с неверным паролем база просто не расшифруется.
- Логин в `localStorage` в открытом виде не лежит: ячейка хранилища называется по хешу логина.
- После выхода из аккаунта ключ и база удаляются из памяти.

> **Внимание:** восстановить забытый пароль невозможно. Без пароля данные аккаунта расшифровать нельзя.

## Запуск на своём компьютере

Открывать `index.html` двойным щелчком нельзя: сайт подгружает `schema.sql`, а шифрованию нужен защищённый адрес. Запустите простой локальный сервер в папке с файлами:

```bash
python -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.

Для работы нужен интернет: библиотека `sql.js` загружается с CDN `cdnjs.cloudflare.com`.

## Публикация на GitHub Pages (бесплатно)

1. Создайте на GitHub публичный репозиторий, например `weriti`.
2. Загрузите в его корень все пять файлов (`index.html`, `style.css`, `app.js`, `sound.js`, `schema.sql`).
3. Откройте **Settings → Pages**, в разделе Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите Save.
4. Через пару минут сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/weriti/`.

HTTPS на GitHub Pages включается автоматически, так что шифрование будет работать.

## Как изменить каталог

Названия, описания и цены лежат в конце файла `schema.sql`, в команде `INSERT OR REPLACE INTO products`. Цена указывается за 1 кг в евро. После изменения файла у пользователей данные обновятся при следующем входе в аккаунт.

## Ограничения

- Данные хранятся в `localStorage` конкретного браузера на конкретном адресе сайта. Аккаунты **не синхронизируются** между устройствами и браузерами.
- Если сменить адрес сайта (например, подключить свой домен), ранее созданные аккаунты в новом адресе не появятся.
- Если пользователь очистит данные браузера, его аккаунт и корзина будут удалены.
- Кнопка «Оформить заказ» пока только очищает корзину и показывает сообщение. Настоящих заказов, оплаты и доставки нет, потому что нет серверной части.
- Проект учебный. Для настоящего магазина понадобятся сервер, база данных на стороне сервера и платёжная система. Кроме того, условия GitHub Pages не разрешают использовать его для интернет-магазинов.

## Технологии

HTML, CSS и JavaScript без фреймворков, sql.js 1.8.0, Web Crypto API, Web Audio API.
